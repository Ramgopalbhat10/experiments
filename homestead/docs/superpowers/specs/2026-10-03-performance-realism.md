# Homestead performance and realism upgrade

User direction: implement every recommendation from the performance/realism review, iterate on issues, and verify completion. Preserve the existing Three.js app, 43 catalog pieces, project JSON version and local saves, desktop controls, and import/export/undo. Work from merged main on an isolated feature branch. No additional approval gates: user explicitly requested continuous execution.

## Acceptance
- Reproducible real-browser benchmark: starter exterior/interior, blank plot, and dense repeated-item scene. Report frame timing, draw calls, triangles, texture/resource counts and device/renderer. A local-GPU runner must be available; cloud SwiftShader results are labeled software rendering and never asserted as proof of 60 FPS on user hardware.
- Automatic quality plus manual Low/Balanced/High settings; bounded resolution scaling, AO and shadows. Stable hysteresis prevents oscillation. Render counters cover all composer passes. Suspend animation while hidden and avoid unnecessary editing work while idle.
- Fixed-step movement with interpolation, smooth acceleration/braking, collision broadphase and capsule-like rounded footprint. Preserve doors, stairs, upper floors, plot boundaries, jumps and pointer lock. Spatial queries update after edits/import/undo. No movement-dependent performance degradation linear in all placed objects.
- Repeated scenery uses spatially partitioned instancing with multiple detail levels, varied vegetation and gentle wind. Editable repeated objects share geometry; selection/raycast/painting continue to identify individual project records.
- Interiors have room-aware ambient/environment response, window/fixture contribution, and local reflection capture updated on edits and lighting changes with bounded cost. Avoid fixed baked lighting assumptions for editable homes. Golden hour synchronizes visible sky and reflected sky.
- Broaden realistic asset coverage for bed, kitchen/bath fixtures or cabinetry, doors/windows where compatible CC0 models are available; preserve scale uniformly and catalog collision footprints. Improve procedural details where imported models would reduce editability. Normalize furniture proportions without stretching.
- Compressed textures and optimized geometry with documented offline recipe and fallback; progressive asset loading and visible progress. Pre-generated catalog thumbnails, no second renderer/43 thumbnail captures during ordinary startup.
- Placement ghost reuses cheap geometry/materials, snapping guide and attachment feedback, subtle optional interaction audio without autoplay. Preserve catalog/inspector keyboard behavior and small-screen controls.
- Unit tests cover motion cadence, collision boundaries, spatial index lifecycle, quality stability, model scale/LOD and resource cleanup. Browser verification covers old workflow plus quality settings, loading, newly streamed models, reflection/lighting, picking repeated instances, resizing and no errors. Capture before/after actual screenshots, review visually and independently; resolve material defects before completion.

## Limits and decisions
Target stable 60 FPS at 1080p on a mainstream hardware-accelerated desktop; provide measurement rather than guarantee for hardware unavailable in cloud. Prefer WebGL2/Three.js compatibility, no engine migration. Assets/fonts remain local with licensing credits. Avoid full-scene path tracing, always-on dynamic cubemaps and expensive transmission. Static reflections update after edits, not each frame. Saves retain original positions and records even if presentation improves.
