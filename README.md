# Experiments

A shared playground for small, self-contained experiments. Each lives in its own folder with its own README.

| Project | What it is |
|---|---|
| [mount-rainier-explorer](./mount-rainier-explorer/) | Firewatch-style three.js hiking game across real Mount Rainier terrain: first/third person, gear, camping, cooking, radio music, stargazing |

Most projects are static: serve the repo root (`python3 -m http.server`) and open the project folder.
